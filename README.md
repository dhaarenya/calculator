# calculator

## Project Overview
This project implements an 8-bit calculator using Verilog HDL and Xilinx Vivado.

## Operations
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Division-by-zero handling

## Project Files
- `calculator` – Main Verilog RTL design.
- `calculator_tb.v` – Testbench for functional verification.

## Tools Used
- Verilog HDL
- Xilinx Vivado

## Simulation
The design and testbench can be simulated using the Vivado Simulator 

### Steps
1. Create a new Vivado project.
2. Add `calculator.v` as a Design Source.
3. Add `calculator_tb.v` as a Simulation Source.
4. Set `calculator_tb` as the simulation top module.
5. Run Behavioral Simulation.
6. Observe the output in the simulation waveform.

## Learning Outcomes
- RTL design using Verilog HDL.
- Arithmetic circuit implementation.
- Testbench development.
- Functional verification using Vivado.
